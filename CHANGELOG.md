# Changelog

## Unreleased

### Initial release

- Run Deban locally in a web browser with a single data store.
- Capture meeting audio, optionally include the microphone, and transcribe English, Japanese and Chinese locally.
- Manage participants, identify speakers and correct transcript speaker assignments.
- Connect a supported AI provider to translate speech, receive meeting prompts, generate suggested replies and summaries, and ask questions about the current meeting.
- Add meeting context, reference materials and notes; review and search meeting history; and export transcripts.
- Store recordings and meeting data locally, import and export `.deban` backups, and recover deleted items for 30 days.
- Use the interface in English, Japanese, Simplified Chinese or Traditional Chinese.
