# Changelog

## 1.0.2

- Fix missing topic summary cards during a meeting. The live view now shows all saved topics, including after reconnecting.

## 1.0.1

- macOS and Windows: Confirming an input method candidate with Enter no longer submits the field.
- macOS: Restore Command shortcuts for cut, copy, paste, and select all.
- macOS: Closing the window keeps Deban running. Click its Dock icon to reopen the window, or press Command–Q to quit.

## 1.0.0

### Initial release

- Run Deban locally in a web browser or as a desktop app for Apple Silicon macOS and Windows x64. Desktop apps include the local backend.
- Capture meeting audio, optionally include the microphone, and transcribe English, Japanese and Chinese locally.
- Manage participants, identify speakers and correct transcript speaker assignments.
- Connect a supported AI provider to translate speech, receive meeting prompts, generate suggested replies and summaries, and ask questions about the current meeting.
- Add meeting context, reference materials and notes; review and search meeting history; and export transcripts.
- Store recordings and meeting data locally, import and export `.deban` backups, and recover deleted items for 30 days.
- Use the interface in English, Japanese, Simplified Chinese or Traditional Chinese.
- Set up microphone access on Windows, and view the app version, website and GitHub links in Settings.
